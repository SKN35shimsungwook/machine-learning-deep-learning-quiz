# ML·DL 용어 퀴즈

혼자 공부하는 머신러닝+딥러닝(개정판) 용어노트를 기반으로 만든 인터랙티브 학습 퀴즈입니다.

- 1장부터 10장까지 전 범위를 다루는 96문항 (개념형 4지선다 + 계산 문제)
- 정답 클릭 시 즉시 채점 및 해설 표시
- 오답노트: 지금까지 틀린 문제만 모아보기
- 자주 틀림: 3회 이상 틀린 문제만 걸러보기, 문제마다 누적 오답 횟수 표시
- 진행 상황은 브라우저 로컬 저장소(localStorage)에 저장

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 실행됩니다. 별도의 빌드나 서버가 필요하지 않은 순수 HTML/CSS/JS 단일 파일입니다.
